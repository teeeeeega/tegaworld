# Tega’s World

Sito statico in italiano per il mondo Minecraft della community di Tega. Non richiede installazioni, build, backend o dipendenze: HTML, CSS e JavaScript nativi.

## Pubblicazione

Pubblica la cartella del progetto su un hosting per siti statici (per esempio Vercel, Netlify o GitHub Pages), mantenendo le cartelle `assets`, `entra` e `privacy` accanto ai file HTML. Non è previsto un comando di build.

## Modifiche

- Social, mappa, logo, indirizzo facoltativo e colori: `site-config.js`.
- Contenuti: `index.html`, `entra/index.html` e `privacy/index.html`.
- Stili, spaziature e responsive: `styles.css`.
- Interazioni leggere: `app.js`.
- Immagini ufficiali originali: `assets/source/`; versioni ottimizzate usate dal sito: `assets/`.

L’indirizzo Minecraft non è pubblicato perché viene condiviso nel Discord dopo la verifica. Il sito non gestisce account, whitelist o dati personali.
